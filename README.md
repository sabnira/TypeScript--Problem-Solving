# TypeScript

## Overview

In this assignment, I practiced core TypeScript concepts by solving 8 problems in a single file, `solutions.ts`. I used basic types, optional parameters, union types with type narrowing, readonly tuples, generics, interfaces, classes with inheritance, and Promises. I also wrote two short blog posts to explain key TypeScript ideas.
